Getting started

  1. Select any cell in Excel that contains a formula.
  2. On the Home tab, choose Explain Formula (in the Formula in Action group).
  3. The task pane opens with a simple explanation, a step-by-step breakdown, a real-world example, any issues it found, and improvement suggestions.
  4. Switch Simple / Technical / In Action mode, or the example's context (Finance, Sales, Supply Chain, ...), from the controls at the top of the pane.

Common questions

Nothing happens when I select a formula.
Make sure the cell's content actually starts with =. A cell that only shows a number or text is not a formula — the pane will say so.

It says "Offline explanation".
The explanation service was temporarily unreachable. You still get the exact functions, step outline, and any detected issues — just a simpler write-up. Use Regenerate to try again.

It says my formula is too long.
Formula in Action explains formulas up to about 8,000 characters. Try explaining a smaller piece of the formula on its own.

Does this work in Excel on the web / Mac?
Yes — the add-in targets Excel on Windows, Mac, and the web.

What data does this send anywhere?
Only the selected formula and light metadata (cell address, sheet/named-range names) — never cell values or your workbook. See the privacy statement for the full picture.

Still stuck?

Contact supportformulainaction@gmail.com with a description of what you selected and what you expected to happen. Screenshots help; please don't send workbooks containing sensitive data.
